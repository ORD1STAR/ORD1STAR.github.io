Master’s final-year project

A brain switch,
stress-tested.

Detecting when someone moves from rest to a command, from 30-channel EEG, for a person the model has never seen. The interesting part was not the model. It was proving the number meant something.

  1. 01
    Record

    10 participants, 28 recordings, 30 channels at 500 Hz, two cue protocols.

  2. 02
    Window

    Causal filters with carried state, 2 s windows with a 0.5 s hop. Nothing sees the future.

  3. 03
    Describe

    Covariance matrices, causal Riemannian re-centering, tangent-space and log-power features.

  4. 04
    Decode

    Riemann fusion, ShallowConvNet, EEGNet and a fixed 50/50 ensemble, scored on held-out people.

  5. 05
    Doubt it

    Drift-matched null models, a time-only control, nested selection and an independent code review.

  6. 06
    Replay live

    A streaming decoder over Lab Streaming Layer: 17 to 19 ms per decision.

What the data said

Negative results,
reported.

Every figure below comes from the repository’s result files. Where a number looked too good, I tried to break it first.

3-class, idle / push / walk

0.385

balanced accuracy. Chance is 0.333 and a drift-matched null scores 0.324. Barely above chance, and written down as such.

Push vs walk, new person

0.514vs0.811

AUC for EEG against a model that only knew the timestamp. A clock beat the brain, so the claim stayed out.

Legacy audit, my own 2025 baselines

98%→36%

median balanced accuracy with random window splits, then with block splits. The leak was in my own earlier work.

Rest vs command, held-out person

0.707 AUC

for the ensemble, with all 10 participants above 0.5. A later review found a baseline bias, so the honest range after correction is about 0.60 to 0.64.

Real-time replay

17–19 ms

per decision on a CPU, with every onset detected on the held-out participant.
